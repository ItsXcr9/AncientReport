# AncientReport
AI System Summary 

## 🚀 Deployment

### Single Server (Default)
For a simple all-in-one deployment:
```bash
docker-compose up -d
```

### Distributed Deployment (Multi-Server)
AncientReport supports a distributed architecture with a central server and multiple remote agents.

**See [DISTRIBUTED_DEPLOYMENT.md](DISTRIBUTED_DEPLOYMENT.md) for the full guide.**

**Quick Start:**

*   **Central Server**:
    ```bash
    ./deploy-central.sh
    ```

*   **Remote Agent**:
    ```bash
    ./deploy-agent.sh
    ```
